# Committed splits

`train.csv`, `val.csv` and `test.csv` are generated by `carvision data split` and are
committed on purpose.

They pin the exact images used for each split, so a number reported in this repository
can be reproduced by anyone who clones it — without re-running the stratified draw and
hoping their library versions produce the same permutation.

`test.csv` is the official Stanford Cars test split, untouched. `val.csv` is a seeded,
stratified 15% carved out of the official train split; `train.csv` is the remainder. No
image appears in more than one file, and `carvision.data.splits.assert_disjoint` enforces
that at generation time.

Regenerating them changes which images are evaluated, which invalidates every published
number — hence the `--overwrite` guard on `carvision data split`.
